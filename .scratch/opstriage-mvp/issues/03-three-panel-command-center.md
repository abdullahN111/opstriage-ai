# 03: Three-Panel Web Command Center (Next.js + Tailwind CSS)

Status: resolved

## Scope
- Build the responsive 3-panel Operations Hub in `frontend/`:
  - **Top Bar**: Live KPI counters, **Live Google OAuth Mode vs. 1-Click Recruiter Sandbox Mode** toggle, "+ New Custom Inquiry" simulator, live Google Sheet viewer modal, and 60-second Demo Walkthrough player.
  - **Left Panel**: Categorized Inbox Queue with Priority badges (`P0`–`P3`), Intent pills, status filters, and 1-click triage trigger.
  - **Center Panel**: Real-time Agent Execution Trace showing each tool call step-by-step with latency, inputs/outputs, extracted entity cards, and matched SOP policy citations.
  - **Right Panel**: Human-in-the-Loop Approval Drawer with editable reply body, AI tone/instruction regeneration, and 1-click **Approve, Send & Mark Sheet Resolved**.
